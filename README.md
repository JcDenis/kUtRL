## ABOUT

_kUtRL_ is a plugin for the open-source web publishing software called [Dotclear](https://www.dotclear.org).

> Use, create and serve short url on your blog

A [user guide in French](https://github.com/JcDenis/kUtRL/blob/master/docs/fr/utilisation.md) is available.

## REQUIREMENTS

* Dotclear 2.40
* PHP 8.1+
* Dotclear admin permission to configure
* No specials permissions to shorten links on the fly

## USAGE

First install _kUtRL_, manualy from a zip package or from 
Dotclear plugins repository. (See Dotclear's documentation to know how do this)

Manage settings, services and short URLs from sidebar menu "URL shortener".
You can also add widgets, template block and values.

With the plugin [ClaudetteMcp](https://github.com/JcDenis/ClaudetteMcp), an AI assistant connected to the blog
can list the short links (`list_short_links`) and create one (`create_short_link`, with the service of the administration),
with the permissions of a blog administrator. ClaudetteMcp is not required by _kUtRL_.
